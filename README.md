# 판도라 라이벌 3D — 별숲의 수호자

HTML, CSS, JavaScript, Three.js로 만든 PC·스마트폰용 3인칭 싱글 플레이 AI 대전 게임입니다. 원작의 모델이나 이미지를 사용하지 않고 기본 도형을 조합한 독창적인 캐릭터와 외계 정글을 사용합니다.

## 실행

1. 저장소를 **Code → Download ZIP**으로 내려받고 압축을 풉니다.
2. `index.html`을 Chrome 또는 Edge에서 엽니다. `game.js`, `style.css`, `vendor` 폴더가 함께 있어야 합니다.
3. 캐릭터와 난이도를 선택하고 **숲으로 출발**을 누릅니다.
4. 마우스 잠금 요청이 나오면 허용합니다. 제한된 브라우저에서는 클릭을 누른 채 마우스를 움직일 수 있습니다.

별도 설치, 빌드, 서버, 외부 모델, 인터넷 연결이 필요 없습니다. Three.js 0.160.1이 `vendor`에 포함되어 있습니다. WebGL과 그래픽 가속을 지원하는 브라우저가 필요합니다. PC에서는 키보드·마우스, 스마트폰에서는 화면 버튼과 드래그로 조작합니다.

## 게임 규칙

- 3분 동안 최대한 많은 상대를 처치하세요. 온라인 멀티플레이가 아닌 AI 대전입니다.
- 빨간 바닥 링과 체력바로 상대를 구분합니다. 링이 깜빡이면 공격 준비 중입니다.
- 쉬움/보통/어려움은 적 체력·이동 속도·피해·수와 조준 보정이 다릅니다.
- 처치마다 경험치 25, 점수 100 + 현재 레벨 × 15를 받습니다.
- 필요 경험치는 40 + 현재 레벨 × 15입니다. 레벨은 1~10이며 적 수와 능력이 상승합니다.
- 레벨 상승 시 체력을 28 회복합니다. 체력 0이면 2.5초 뒤 리스폰하며 3초 동안 보호됩니다.
- 총알은 무제한입니다. 대포는 가까운 여러 적에게 거리별 피해를 줍니다.
- 명중 숫자·파티클·조준점 명중 표시·흔들림·합성 효과음이 적용됩니다. 유혈 표현은 없습니다.
- 일시정지하거나 다른 창으로 이동하면 시간이 멈춥니다.
- 최고 점수는 현재 브라우저에만 저장됩니다. 저장소 접근이 제한되어도 게임은 실행됩니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하세요.
이후 **Actions → Deploy Pandora Rivals → Run workflow**로 배포할 수 있습니다. `main`에 변경이 올라오면 자동 배포합니다.
배포가 성공하면 `https://reiner5427-eng.github.io/My-app/`에서 플레이할 수 있습니다.

Netlify를 사용한다면 이 저장소를 연결하고 빌드 명령은 비워 두고 게시 디렉터리를 `.`으로 지정하면 됩니다. 계정 인증이 필요합니다.

## 파일

- `index.html`: 한국어 UI 및 게임 진입점
- `style.css`: 네온 UI, HUD, 선택/일시정지/결과 화면
- `game.js`: 모델·정글 생성, 물리, AI, 전투, 카메라, 소리
- `vendor/three.min.js`, `vendor/THREE-LICENSE.txt`: Three.js와 MIT 라이선스
- `tests/test-game.cjs`: 게임 로직 검증
- `.github/workflows/deploy.yml`: GitHub Pages 배포

## 검증

Node.js가 있으면 `node --check game.js`와 `node tests/test-game.cjs`를 실행합니다.
실제 게임 스크립트와 Three.js 수학/도형을 실행하며, DOM·WebGL 렌더러는 모의 객체로 대체합니다.
4종 무기 명중, 이동/달리기/점프, 경계 충돌, AI 공격, 사망/리스폰, 난이도, 레벨 10 제한, 일시정지, 전체 180초 진행, 종료/재시작 등 15개 검증을 통과했습니다.
브라우저 자동화 권한이 거부되어 실제 GPU 화면·마우스 잠금·소리의 시청각 검증은 수행하지 못했습니다. 기기별 프레임 속도는 다를 수 있습니다.

## 기술 메모

이동은 델타 시간 기반이며 투사체는 이전/현재 위치 사이 선분으로 충돌을 검사합니다. 고정 부품은 재질별로 합쳐 그리기 호출을 줄이고, 파티클 수를 제한합니다. 물리 계산은 프레임당 0.05초로 제한하고 라운드 타이머는 실제 경과 시간을 사용합니다.
`?test`를 붙인 주소에서만 로컬 테스트 어댑터가 노출됩니다. 별도 서버나 사용자 계정 데이터는 없습니다.

## 스마트폰 조작

작은 화면(900px 미만) 또는 터치 기기에서 게임을 시작하면 방향키와 공격·점프·달리기 버튼이 표시됩니다. 빈 전장을 드래그하면 시점을 움직여 조준합니다. 이동·공격·점프·달리기는 누르고 있는 동안 계속 적용되며 여러 손가락으로 함께 조작할 수 있습니다. 화면 상단의 일시정지 버튼으로 멈춥니다.

Pointer Events와 포인터 캡처를 사용하며, 미지원 브라우저에서는 Touch Events로 처리합니다. 손가락을 떼거나 터치가 취소되면 해당 입력을 해제합니다. 일시정지·앱 전환·재시작·메뉴·경기 종료 시 모든 입력을 초기화합니다. PC 키보드 입력과 가상 버튼 입력은 별도로 관리합니다. 작은 화면과 가로 화면, 화면 안전 영역에 맞춰 버튼과 HUD를 배치합니다.

`node tests/test-mobile.cjs`로 연속 이동·공격, 동시 입력, 같은 버튼의 복수 접촉, 키보드 혼용, 점프, 드래그 조준, 터치 취소, 일시정지·앱 전환·종료 후 초기화를 검증합니다. 포인터 경로와 터치 대체 경로 합계 14개 검증 및 기존 게임 15개 검증이 통과했습니다. 배포 워크플로에서도 둘 다 실행합니다.

검증 한계: 로컬 주소의 브라우저 접근 승인이 거부되어 실제 GPU 렌더링, 320px 화면의 시각적 배치와 실제 iOS/Android 다중 터치는 검증하지 못했습니다. 테스트는 실제 게임 코드를 실행하되 DOM·WebGL·입력 이벤트를 모의 처리합니다.
